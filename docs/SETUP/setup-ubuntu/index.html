1.1 Setting Up Ubuntu on External PC

This guide provides a detailed walkthrough for setting up an Ubuntu environment, containerization with Docker, and running a Docusaurus project using Visual Studio Code.

1. Download Ubuntu ISO​

Visit the Ubuntu website to download the appropriate ISO file for your system.

2. Flash the ISO to a USB Drive​

Use tools like balenaEtcher to flash the Ubuntu ISO to a bootable USB drive.

3. Boot the Ubuntu image​

You can now boot the Ubuntu image into the external PC. You should see something like this:

note

If the PC does not recognise the installation media automatically, you can choose to restart and enter the BIOS by hitting F12 or del button repeatedly.

4. Installation of Ubuntu:​

Follow the on-screen instructions to install Ubuntu. You can choose to configure network settings during installation. After setting up the system, you can now install Ubuntu in the PC.
